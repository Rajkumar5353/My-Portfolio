📸 IMAGES KE LIYE GUIDE

Ye files `images/` folder mein rakhne hain:

1️⃣ PROFILE PHOTO (profile.jpg)
   - Size: 300x300 pixels (square)
   - Format: JPG ya PNG
   - Type: Tera professional headshot
   - Where to get: Apne phone se lelo ya Unsplash se (free)
   - Unsplash: https://unsplash.com/s/photos/profile

2️⃣ PROJECT 1 PHOTO (project1.jpg)
   - Size: Koi bhi width, height ~200-300px
   - Format: JPG ya PNG
   - Type: Project ka screenshot ya demo
   - Where to get: Apne project ka screenshot lo, ya Unsplash

3️⃣ PROJECT 2 PHOTO (project2.jpg)
   - Phir se koi bhi project screenshot

4️⃣ PROJECT 3 PHOTO (project3.jpg)
   - Aur ek project ka screenshot

🎯 TIPS:
- Square ya landscape photos best hain
- Quality zyada ho (minimum 500x500px for profile)
- Compressed ho (taki load jaldi ho)
- Professional dikhne wale photos use karo

💡 FREE IMAGE SOURCES:
- Unsplash: https://unsplash.com
- Pexels: https://pexels.com
- Pixabay: https://pixabay.com
- Screenshot khud: Windows key + Shift + S (Windows) ya Cmd + Shift + 4 (Mac)
